Marine foundation models

2023 – 2024

ECCV 2024 · Oral

MarineInst

A Foundation Model for Marine Image Analysis with Instance Visual Description

A marine foundation model that describes each object it finds. It first segments every instance, then writes a semantic caption for each mask; binary instance filtering removes non-instance masks in training and inference. One model serves tasks from image-level scene understanding to instance-level analysis.

CVPR 2024 · Highlight

CoralSCOP

Segment any COral Image on this Planet

The first foundation model for dense coral reef segmentation. A parallel semantic branch in the mask decoder gives every mask a meaning, so the model traces irregular coral boundaries at several levels of detail (coral or non-coral, growth form, genus) and segments unseen reef images zero-shot.

arXiv 2023

MarineGPT

Unlocking Secrets of “Ocean” to the Public

The first vision-language model built for the marine domain. Marine-specific continuous pre-training aligns a vision encoder with a large language model on marine image–text pairs; instruction-following fine-tuning then teaches it to give sensitive, informative and scientific answers about marine life.

Computer vision & multimodal sensing

ECCV 2026

MarineEVT & EVT-R1

Advancing Event-Centric Marine Video Understanding via Visual Tool Reasoning

EVT-R1 treats marine video understanding as multi-turn reasoning with visual tools, finding the sparse, brief events in long underwater footage. Turn-level reinforcement learning with a dual reward, one for valid tool use and one for correct answers, teaches the model when and how to use each tool.

IEEE RA-L 2026

MaskGuide

Efficient Distillation for Deployable Lightweight Segmentation in Marine Environments

Feature-level distillation for segmentation on underwater robots. MaskGuide separates the teacher’s features into foreground and background and fuses them into a cleaner training signal. The resulting Tiny-MSAM encoder keeps 99.4% of SAM’s accuracy with 3.5M parameters at 164.7 FPS.

Project page ↗Paper ↗Code ↗

ICCV 2025

CoralSRT

Revisiting Coral Reef Semantic Segmentation by Feature Rectification via Self-supervised Guidance

An add-on module that rectifies features from pretrained foundation models for coral segmentation. Different corals look very unalike, but each coral is strongly self-similar; CoralSRT uses this as self-supervised guidance to steady coral features and improve label propagation, with no human annotation, no retraining and no domain-specific data.
